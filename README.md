# 生産管理

ゲームの生産ツリー、必要素材、施設数をブラウザで見るツールです。データは `data/*.yaml` を手で編集します。

## 起動

```powershell
go run .
```

ポートとデータディレクトリを変えるときは `go run . 8080 data` です。起動すると `http://localhost:8080/` と、同じネットワークの端末から開く URL を表示します。`/` がホスト、`/client` がクライアントです。ゲーム、アイテム、目標速度はサーバに1つだけあり、どちらの画面で変えても、約1秒以内にもう一方へ出ます。ホスト画面上部の「接続」から、クライアントを開くQRコードを表示できます。種類や名称の絞り込み、必要素材の表示切替、テーマ、全画面は、その画面だけに残ります。

## 画面

ゲーム、種類、名称でアイテムを絞り、アイテムを選ぶと生産ツリーが出ます。完成品が上、材料が下です。生産ツリーはホストだけに出ます。クライアントはゲーム、種類、名称、アイテムの選択と、必要素材、必要施設数、目標速度の表示ができます。

目標速度は「1秒あたり何個か」です。空欄のときは、選んだアイテムの先頭レシピが1回で出す個数を速度として使います。`0.5` のように小数も入れられます。

必要素材の「すべて」は原材料と中間素材の両方です。「1次素材のみ」は、採取や採掘のように先頭レシピの材料が空の行だけです。個数に端数があるときは、表示で切り上げます。

必要施設数は、目標速度を1台あたりの産出速度（個/秒）で割って切り上げた台数です。生産時間が無いアイテムは施設数を出さず、その旨を表示します。必要素材の表示では、生産時間が無くても必要個数を出します。
